      Formats

        Vector Free

        Turns bitmaps (PNG, JPG…) into scalable vector art.

        Workflow

        1. Open, drop or paste an image. With fully automatic mode it is vectorized right away.
        2. Check the image type: zoom in on an edge — if colors blend smoothly it is blended.
        3. Quality describes the source (artwork) or the level of detail you want (photos).
        4. Use Suggested palettes or the eyedropper for logos with 12 or fewer colors.
        5. Compare with Overlay/Outlines, fix mistakes with Pencil, Fill and Zap, then Export.
